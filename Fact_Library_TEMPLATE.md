# Fact library

Atomic, fact-checked building blocks for drafting tailored resumes and cover letters. Every
entry above **The fence** at the end of this file has been confirmed by me. Anything I am not
yet sure of lives in `Open_Questions.md`, never here.

When drafting an application, select the entries whose tags match the job ad's stated
requirements and build up from them. Do not start from a fixed resume and trim. Do not
paraphrase away the specifics — numbers, named employers, named systems — that make an entry
checkable.

## The fence — everything above this line is licensed

Every entry above has been confirmed by me. A drafting agent may use any of it without
checking further. That guarantee holds only because nothing unconfirmed is allowed above this
line.

Unconfirmed items live in `Open_Questions.md` at the repository root. Do not use one until I
have answered it, and do not write a new one into this file: put it there and leave this fence
intact.

**Silence is not a gap.** If an ad names a skill that appears nowhere above, that means nobody
has asked me about it — not that I lack it. Recorded gaps are the **Recorded gaps** section,
and they are explicit.
