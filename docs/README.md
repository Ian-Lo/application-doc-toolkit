# Documentation index

Read order, if you are new to the toolkit:

1. **`Getting_Started.md`** — from nothing to a finished resume and cover letter, in the
   browser. Start here if you are the person applying for jobs.
2. **`Fact_Library_Guide.md`** — the file every document is built from: what an entry is,
   where facts come from, the fence, and how to build it by conversation. The templates it
   refers to are `../Fact_Library_TEMPLATE.md` and `../Open_Questions_TEMPLATE.md`.
3. **`../CLAUDE.md`** — the orchestrator's rulebook. Everything else hangs off it.
4. **`Conventions_Rationale.md`** — why each rule exists: the incident that produced it, on
   the real corpus this toolkit was extracted from. Read an entry when a rule looks arbitrary.
5. **`Writing_Style.md`** — read before drafting or revising any outgoing document. The voice
   model, the LLM tells to avoid, and the hard rules for handling gaps.
6. **`Review_Checklist.md`** — read before reviewing any draft. The subtractive accretion
   diff, the two failure directions, and the verdict rules.
7. **`Recon_Checklist.md`** — read before researching a company. Topic list and source rules.

The agent role definitions in `../.claude/agents/` carry role-facing duplicates of a few rules
from these files. The duplicates are deliberate and marked; each names its canonical copy.
